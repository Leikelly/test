# 婚宴出席回函

張大明 & 余小嬌 的喜宴出席回函頁面，包含：

- **前台表單**：姓名、電話、Email、男方／女方親友、親友分類、成人與兒童人數、兒童椅、葷素份數、喜帖地址、給新人的祝福
- **新人後台**：回函份數、出席人數、預估桌數、葷素統計、兒童椅、親友分類圖表、回函明細（可搜尋篩選、匯出 CSV）、祝福留言牆

## 注意

這個頁面的資料儲存使用 Claude Artifact 的執行環境（`window.claude`）。
直接用瀏覽器或 GitHub Pages 打開時，畫面可以正常顯示，但無法送出回函，後台也不會有資料。
實際收回函請使用 Claude 上發布的版本。
